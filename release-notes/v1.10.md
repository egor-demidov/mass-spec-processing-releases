# Version 1.10

- Added the ability to estimate and subtract background signal from experimental spectra
- Improved mixture solver stability
- Fixed numerous bugs:
  - After loading a present with a different compound in ‘search mixture’,
  the code ignores what is in the compound field and keeps using the old formula
  - Profile spectrum will not be previewed if no centroid peaks were generated
  - If there are repeated m/z points in profile spectra, the peak picker algorithm will not return any peaks
  - If mixture solver does not run because ‘compounds are not aligned’ and a search is attempted after that - will get an error “QThread: Destroyed while thread '' is still running”
